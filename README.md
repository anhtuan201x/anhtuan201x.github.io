## 📱 Hướng dẫn thêm nguồn vào Cydia

1. Mở **Cydia** trên iPhone/iPad.
2. Vào **Sources**.
3. Nhấn **Edit**.
4. Nhấn **Add**.
5. Nhập địa chỉ:

https://anhtuan201x.github.io/

6. Nhấn **Add Source**.
7. Chờ Cydia tải Packages hoàn tất.
