# AnhTuan Repo

Kho luu tru Tweak va Ung dung Legacy danh rieng cho thiet bi iOS 6.

## 🚀 Huong dan them nguon vao Cydia
1. Mo ung dung **Cydia** tren chiec iPhone/iPad cua ban.
2. Chuyen sang tab **Sources** (Nguon) -> Bam **Edit** -> Bam **Add**.
3. Dien chinh xac dia chi mang sau: `http://github.io`
4. Bam **Add Source** va cho cho may nạp Packages hoan tat.

## 📦 Cac tweak dang co san
* AppSync Unified (Legacy Arm)
* AppStoreFix (Sua loi cho iOS 6)
* Veteris (Cho ung dung co xua)
